## 本批：Mac 界面还原与按键修复

- 用户反馈 Mac 查字/设置与 Windows 差距大、到处是多余阴影，且 Mac 上单击 Shift 不能切英文，另要求全角/半角能用按键切换。先交 HTML 预览（`artifacts/ui-preview-20261031/preview.html`），用户同意后实施。

- 单击 Shift 根因（真机诊断确认）：IMK 把每个修饰键事件投递两次（按下、按下、抬起、抬起）。旧判定把同一 Shift 的第二次按下当成“期间有其他键”而作废单击，因此真机从不切换。首轮按“发送对象不同被拒”的假设放宽了检查，装上后仍不能切换。由于产品未开调试权限、LLDB 无法附着，改装临时诊断版，只在内存计数，并显示在输入法菜单末行。用户截图显示：修饰键事件 44 个、发送对象不同 0 个、单击 4 次、切换 4/0，最近四个事件为 ⌘ 的按下与抬起各两次。据此撤回放宽，恢复按发送对象严格核对；判定改为同一键码重复报告的按下保留单击，另一个 Shift 或其他修饰键介入仍作废。诊断代码已全部删除。
