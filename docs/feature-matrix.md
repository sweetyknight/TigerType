# 功能基线与后续验收矩阵

固定资源见 `resources/tiger.lock.json`；自动样例见 `fixtures/engine-smoke.json`。
当前样例由 Rust 原生子进程测试执行，旧 Python 工具已删除；运行命令见 README。
这些样例只建立 librime 1.17.0 + 给定资源的独立引擎基线，**不是原小狼毫的实测候选金标准**。
“输出已验证”不等于相应 TSF、界面或快捷键已实现。

## 配置差异需要保留

- 默认方案列表为 `tiger`、`tigress`、`PY_c`；依赖 `core2022`、`easy_english`、`stroke`。
- 虎码自定义补丁使用九候选；PY_c 的独立样式含 `inline_preedit: false`，不能用全局设置抹平差异。
- 原包含 7 个启用 Lua 模块；`dz_ci_filter` 已禁用，仍禁用。
- 手机键盘选项不在 Windows 实施范围。特殊字体不自动安装。
- 原包没有完整基础配置，已固定官方 prelude 与 essay 作为本项目的部署基线；旧程序实际基础数据版本未知，因此候选一致性仍须对照实测。
