# TigerType

TigerType 是专为[虎码](https://huma.ysepan.com/)编写的输入法，用 Rust 实现，不依赖 Rime。默认单字输入，也可切换为词输入。所有数据都在本机，没有云同步、遥测或自动更新。

| 平台 | 状态 |
|---|---|
| Windows 10/11 x64 | 可安装使用，支持 64 位和 32 位应用 |
| macOS 13+（Apple 芯片） | 开发中，已能安装和打字，尚未完成完整验收 |
| Linux | 开发中：查字与设置界面已完成，输入法尚不可用 |

各平台实际验收到哪一步，以[项目状态](docs/project-status.md)为准。

## 功能

**输入**

- 单字、词两种模式。词模式与官方词版一致，字和词都能打。候选按官方码表权重排序，不造词、不调频
- 四码待选，下一码顶屏；可开启四码唯一时自动上屏
- 默认只出常用字，可切换为全字集
- 上屏字形可选原字、简体或繁体，一对多时全部列为候选
- 反引号 `` ` `` 进入拼音反查：输入无调全拼，可查字也可查词（音节连写，如 `nihao`），词会显示词码，支持多音字和 ü/v，选中的字或词直接上屏
- 全角/半角、中英文标点随时切换
- 随包字体覆盖码表全部单字，无需另装字体

**候选窗**

- 竖排，每页 3–9 个候选（默认 5 个），支持鼠标点选
- 可在候选旁显示虎码拆分与编码，输入时也能用 `Ctrl+L` 临时切换
- 候选字体可选霞鹜文楷或楷体
- 配色有琥珀、墨、竹、玫红和自定义；界面不使用蓝色（系统高对比度模式和 macOS 系统菜单除外）

**查字**

- 独立窗口，输入拼音、词码或粘贴汉字/词即可查询，边输边查，始终查全字集
- 显示可用编码、完整编码、读音和拆分，拆分的每个字根下方标出它的大码和小码；查词时按字列出完整编码和拆分，读音优先用官方词读音；缺资料时明确标注
- 可一键复制当前字的全部资料；不读取或监视剪贴板

**设置**

- 分输入、外观、快捷键、高级四区，修改立即生效，打字时也能改
- 配置保存在带中文注释的 `settings.toml`，也可手动编辑后在“高级”页重新载入

## 快捷键

| 操作 | 按键 |
|---|---|
| 切换中英文 | 单击 `Shift` |
| 切换中英文标点 | `Ctrl+.` |
| 全角与半角 | `Shift+Space` |
| 拼音反查 | `` ` `` 后输入拼音 |
| 首选上屏 | `Space` |
| 选择候选 | 数字键，或 `;` 第二项、`'` 第三项 |
| 移动高亮 | 方向键 |
| 翻页 | `-` `=` `PgUp` `PgDn` |
| 编码原样上屏 | `Enter` |
| 取消输入 | `Esc` |
| 显示拆分与编码 | `Ctrl+L` |

macOS 上 `Ctrl` 即 `⌃` 键。

## 打开查字和设置

**Windows**

- 正在用 TigerType 时，任务栏显示“中”或“英”：单击切换中英文，右键菜单可切换全角、标点，并打开查字和设置
- 其他时候，通知区显示虎码印章图标：单击打开设置，右键可选查字或设置。Windows 11 默认把新图标收在“^”里，可在“设置 → 个性化 → 任务栏 → 其他系统托盘图标”中常显
- 也可从开始菜单打开“TigerType 查字与设置”，后台没运行时会一并启动

**macOS**：从菜单栏的输入法菜单打开。

## 安装

目前没有发布安装包，需要从源码构建。构建环境见[开发命令](docs/implementation-plan.md#开发命令)。

### Windows

```powershell
cargo fetch --locked
cargo run --locked --offline -p tigertype-dev --example package
```

1. 双击运行生成的 `target\package\TigerType-Setup-<版本>.exe`，它会自行请求管理员权限。
2. 在“设置 → 时间和语言 → 语言和区域 → 中文(简体) → 语言选项 → 键盘”中添加“TigerType 虎码”。

升级时直接运行新版安装包。已打开的程序要重开才能打中文，安装程序的准备页可以代为关闭。卸载在“设置 → 应用”中进行，用户数据和字体会保留。

### macOS

```sh
cargo fetch --locked
cargo run --locked --offline -p tigertype-dev --example package
sudo target/package/TigerType.app/Contents/MacOS/tigertype install
```

首次安装后注销并重新登录，再到“系统设置 → 键盘 → 文本输入 → 编辑”中添加“TigerType 虎码”。升级使用同一条安装命令；开发期不兼容旧版安装包，若提示已有包不符，请先用下方命令卸载已安装版本，再安装新版。

安装会补齐缺失字体，保留已有的有效字体。如果提示已有字体损坏或文楷缺少虎码字根，请先核对提示中的文件，移除冲突字体后重新安装；安装器不会覆盖这些文件。

卸载命令如下，用户数据和字体会保留，输入法条目需在系统设置中手动移除：

```sh
sudo '/Library/Input Methods/TigerType.app/Contents/MacOS/tigertype' uninstall
```

## 数据位置

- 设置和用户数据：Windows 在 `%APPDATA%\TigerType`，macOS 在 `~/Library/Application Support/TigerType`；配置文件为其中的 `config/settings.toml`
- TigerType 不读取个人词库，也不改动已有的其他输入法
- 码表取自虎码官网盘的“虎码秃版 小狼毫（Win）”方案包（2026.08.14），字体来源见 [`resources/fonts.lock.json`](resources/fonts.lock.json)

码表与字体的授权尚未确认，仅供个人使用，安装包不公开发布。
